## Đã triển khai

1. Package version 0.3.0 và CLI luna: demo/configure/doctor/logs/recover/telegram.
   Không dependency runtime bên thứ ba; setuptools chỉ là build backend.
2. Wizard cấu hình không hỏi/lưu token; tạo file riêng, không ghi đè.
   User IDs, db_path và rate_limit được validate; environment có thể override.
3. Telegram polling có bounded exponential reconnect, xử lý HTTP 429 retry_after,
   không retry 401/403/409; lỗi mạng/API được che URL/token/response riêng tư.
4. Checkpoint theo public bot ID trong SQLite; resume qua restart; offset cũ hết
   hạn được reset sau 24h để tránh chặn ID random mới. Khóa OS một poller/database.
5. Allowlist int dương, matching private chat, giới hạn 20 lệnh/user/phút mặc định.
   Không tạo rate bucket cho user lạ; giới hạn 100 user, queue được cắt theo cửa sổ.
   Lệnh quyết định có date quá 5 phút bị chặn.
6. /system và /logs chỉ trả trạng thái/event, không payload/result/path.
   Approve/reject ghi actor Telegram ID trong cùng audit transaction.
7. SQLite schema v3 upgrade v1/v2, giữ task/audit/timeout/attempts.
   New POSIX DB/config mode 0600; existing permissions được giữ nguyên.
   Recovery CLI đòi --confirm-stopped và khóa poller; không tự replay task running.
8. Quick Start, Windows/Linux setup, recovery/backup, security, CHANGELOG,
   JSON ví dụ và systemd template (không tự cài).
9. CI bổ sung pip install . và luna demo từ ngoài source, giữ matrix
   Python 3.10/3.11/3.12 trên Ubuntu và Windows.

## Giới hạn / kiểm tra owner còn lại

- Không dùng token thật, không gọi bot thật hay gửi tin nhắn. Khả năng live chưa
  được kiểm chứng; cần owner chạy riêng theo docs/TELEGRAM.md.
- Mục tiêu Quick Start khoảng 10 phút chưa được đo với người mới.
- Khóa chỉ cùng database/host; không khóa toàn cục cùng bot token trên nhiều máy.
- Quyết định, checkpoint và sendMessage không cùng transaction. Checkpoint trước
  reply có thể mất reply sau lỗi mạng; crash giữa decision/checkpoint có thể nhận
  lại quyết định, nhưng state guard chặn thay đổi lặp. Không bảo đảm exactly once.
- Anti-spam per process/RAM, reset sau restart, không phải anti-DDoS phân tán.
- User allowlist chia sẻ mọi quyền quản lý; chưa có tenancy/RBAC chi tiết.
- Config, database và backups chứa thông tin cá nhân/user IDs hoặc plaintexttask.
  POSIX mode được bảo vệ cho file mới; Windows cần owner kiểm tra ACL.
- Doctor chỉ là kiểm tra local, không xác nhận token/live connectivity.
- Supervisor crash có thể để lại worker sống; phải stop/verify mọi executor/worker
  trước manual recovery. Flag là xác nhận của operator, không tự tìm mọi orphan.
- Deadline opt-in; inline None không timeout. Không hỗ trợ descendant process tree,
  code không tin cậy hoặc rollback side effects.
- Template service chưa được cài/test trên hệ điều hành thật như một daemon/service.
- PyPI/public release/tag cần phê duyệt riêng sau review.

Nguồn giao thức: https://core.telegram.org/bots/api
