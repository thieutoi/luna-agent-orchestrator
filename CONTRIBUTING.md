# Contributing

Contributions are welcome. Please open an issue describing the change before large pull requests.

1. Fork the repository and create a feature branch.
2. Run `python -m unittest discover -s tests -v`.
3. Add tests for behavior changes.
4. Never include credentials, private data, or code copied from private repositories.
5. Submit a pull request with a concise description.

All contributions must be your own or appropriately licensed.
